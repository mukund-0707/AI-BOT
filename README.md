# AI-BOT

AI-BOT is a Django-based chatbot project with a structured backend and frontend assets.

## Project Structure

- app/ — frontend templates and static assets
- backend/ — Django project and app modules
- docs/ — project documentation
- pyproject.toml — Python project configuration
- uv.lock — dependency lock file

## Development Plan

- Set up the core bot structure and repository workflow.
- Add initial features and document usage steps in this README.
- Test changes locally on the development branch before considering any merge to main.
- Review and refine the project plan as new requirements are added.

## Getting Started

1. Install dependencies with uv or pip.
2. Run the Django backend from the backend directory.
3. Open the app locally to test the chatbot experience.
